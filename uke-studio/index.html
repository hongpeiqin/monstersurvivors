上传干净的独奏 / 哼唱，选择最多 15 秒的片段并手动设定 BPM。复杂混音、噪声、重复音的起点可能不准；调性为估计，弹唱和弦是旋律推导的推荐，不是原曲识别结果。

谱面可改弦品、时值、和弦，支持撤销重做；试听基于当前谱面。SVG / PNG 为谱面导出，MIDI 为当前编配，JSON 用于继续编辑。导出 PDF 使用浏览器打印。未实现歌词对齐、完整多声部转写与 MusicXML 导出。

音频只在本设备处理，不会上传。草稿只保存谱面，不保存录音。请勿把 API Key 输入此公开静态页面。
